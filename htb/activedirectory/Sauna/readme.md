
AS-REP Roasting 

Kerberos c'est le système d'authentification de Windows/Active Directory. Quand tu veux te connecter, normalement ça se passe en 2 étapes :

AS-REQ → ton PC envoie une preuve que t'es bien toi (pré-authentification) chiffrée avec ton mot de passe
AS-REP → le DC répond avec un ticket chiffré
